# Functions that check-guide.R cannot look up, but which ARE correct.
# One name per line. Always write down WHY, or the file grows into a rug that
# real errors get swept under.

# tdc() and event() are not exported by survival. They exist only as special
# functions evaluated inside tmerge()'s non-standard evaluation, so an ordinary
# lookup in the package's exports never finds them. The usage is correct.
tdc
event

# := on the left of mutate(!!name := value) is never called as a function.
# dplyr reads it as tidy-eval syntax for a column name held in a variable,
# so it works with library(dplyr) alone. The checker otherwise maps it to
# data.table, which exports a function of the same name.
:=

# closest() only exists inside dplyr::join_by() (rolling joins, dplyr >= 1.1.0).
# It is not exported as a function, so the checker cannot look it up.
closest
